# C言語によるキャラクター管理システム（ルイーダの酒場）

## 概要
上司作成の仕様書（画面遷移図・パラメータ定義）に基づき、C言語で構築したコンソールアプリケーションです。
仕様書に沿った基本機能（CRUD操作等）の実装にとどまらず、実務を見据えた「不正入力対策」や「外部ストレージ（初代PSのメモリーカード風）を意識したファイル入出力処理」の追加など、安全性を考慮した機能拡張を行いました。

---

## 主な機能一覧
- **Read（閲覧）:** 全員表示 / 特定キャラクターの閲覧
- **Create（追加）:** 名前・性別・職業の新規登録
- **Delete（削除）:** 個別削除 / 全削除
- **Sort（並び替え）:** 性別順・職業順のソートアルゴリズム
- **Save / Load（永続化）:** 外部管理フォルダ内 `Memory_Card.txt` への入出力処理

---

## 設計・実装における技術的取り組み（コードのポイント）

### 1. 仕様書の忠実なキャッチアップと段階的な機能拡張
* 提示された画面遷移図・各種パラメータ制約を正しく理解し、基本機能からソート、動的メモリ管理までを段階的に構築・拡張しました。

### 2. 事前サイズ取得による動的メモリ確保（`calloc`）
* ファイル入出力時（`get_target_file_size`）において、`fseek(..., SEEK_END)` と `ftell` を用いて事前に対象ファイルのサイズを正確に測定。
* 固定長配列に頼らず、算出したサイズに応じて `calloc` で動的にメモリ領域を確保し、ゼロ初期化を同時に行うことでメモリ効率と安全性を両立させました。

### 3. バッファオーバーラン・改行コード対策
* 安全機能付き関数（`fopen_s`, `sprintf_s`）および `fgets` による指定長読み込みを採用。
* `strcspn(..., "\r\n")` を用いてOSごとの改行コード（CR/LF）を確実にヌル文字に置換し、文字列境界の保護と安全な整形を行っています。

### 4. 有効データ件数（`src_data_counter`）による描画・出力制御
* 描画・一覧出力処理（`test_printer`）では、確保した最大領域サイズではなく、実際にファイルから読み込めた「有効データ件数」をカウントして引数として渡す設計を採用。
* 未初期化領域やゴミデータへの不要なアクセス・異常表示を防ぎ、正確なデータのみを出力する制御を行いました。

### 5. 外部ストレージを意識したフォルダ構成
* 外部メディア（初代プレイステーションのメモリーカード等）へのアクセスを模し、外部に管理フォルダおよび `Memory_Card.txt` を配置してデータロードを行うアーキテクチャで設計しました。
