# C言語によるキャラクター管理システム（ルイーダの酒場）

## 概要
上司作成の仕様書（画面遷移図・パラメータ定義）に基づき構築した、C言語によるコンソールアプリケーションです。
仕様書に沿った基本機能（CRUD操作・ソート等）の実装にとどまらず、実務を見据えた「不正入力対策」や「初代PSのメモリーカード風外部ストレージを意識した動的ファイル管理システム」の構築など、安全性と拡張性を考慮した機能追加を行いました。

---

## 主な機能一覧
* **Read（閲覧）:** 全員表示 / 特定キャラクターの閲覧 / 外部フォルダパスの一覧表示
* **Create（追加）:** 名前・性別・職業の新規登録 / セーブデータ追加に伴う管理配列の動的拡張
* **Delete（削除）:** 個別削除 / 全削除 / データ削除およびアクセス不可時の管理配列自動縮小
* **Sort（並び替え）:** 性別順・職業順のソートアルゴリズム
* **Save / Load（永続化）:** 外部管理ヘッダーの読込・更新および `Memory_Card.txt` への入出力処理

---

## 設計・実装における技術的取り組み（コードのポイント）

### 1. 仕様書の忠実な理解と段階的な機能拡張
* 提示された画面遷移図・各種パラメータ制約を正しく分析し、基本機能から双方向リストによるソート、動的メモリ管理までを段階的に構築・拡張しました。

### 2. 外部ストレージを意識した動的セーブデータ管理
* 初代プレイステーションのメモリーカード構造を模し、外部管理フォルダ内に管理用ヘッダーデータを配置。
* 起動時にヘッダーから取得したパス配列を基にセーブ・ロードを行う仕様へ改修し、新規セーブ追加時には `realloc` で管理配列を動的拡張するロジックを実装しました。

### 3. 未存在データ検知とメモリの動的縮小・安全制御
* 記録されているパスから本体データへのアクセスが失敗（ファイル消失・破壊）した場合やデータ削除時、自動で管理配列サイズを縮小（`realloc` / `memmove`）させ、メモリの健全性と安全性を保持する仕組みを構築しました。

### 4. 事前サイズ取得による動的メモリ確保（`calloc`）
* ファイル読込時（`get_target_file_size`）において、`fseek` と `ftell` を用いて対象ファイルサイズを正確に計測。
* 固定長配列に頼らず、算出したサイズに応じて `calloc` で動的にメモリ領域を確保し、ゼロ初期化を同時に行うことでメモリ効率と安全性を両立させました。

### 5. バッファオーバーラン・改行コード・境界値対策
* 安全機能付き関数（`fopen_s`, `sprintf_s`）および `fgets` による指定長読み込みを採用。
* `strcspn(..., "\r\n")` を用いた改行コードのクリアや、UI上の選択番号（1始まり）と配列インデックス（0始まり）の境界値オフセット処理を徹底し、入力不整合や領域外アクセスを防止しました。
